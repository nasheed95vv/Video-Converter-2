## 1. Коротко
- Ваши файлы обрабатываются только на вашем устройстве. Приложение не загружает их на серверы Разработчика или других лиц.
- В приложении нет регистрации и учётных записей, а Разработчик не собирает собственную аналитику и не ведёт серверов с данными пользователей.
- В приложении показывается реклама сервиса Yandex Mobile Ads (Яндекс). Рекламный SDK может обрабатывать технические данные устройства (см. раздел 3).

## 2. Какие данные использует приложение
**2.1. Ваши файлы.** Вы сами выбираете файлы через системное окно выбора или через пункт «Поделиться». Приложение читает их только для сжатия. Результат сохраняется как новая копия в папке по умолчанию или в папке, которую вы выбрали. Исходные файлы не изменяются и не удаляются. Разработчик не получает доступа к вашим файлам и их содержимому.

**2.2. Данные приложения на устройстве.** Приложение хранит локально: историю сжатий (имена файлов, размеры, ссылка на результат, время), суммарную статистику экономии места, настройки (тема, папка сохранения) и состояние отключения рекламы (дата окончания и прогресс просмотренных роликов). Эти данные не покидают устройство и удаляются кнопкой «Очистить» в разделе «История», очисткой данных приложения или его удалением.

**2.3. Временные файлы.** Во время сжатия создаются временные файлы в кэше приложения. Они удаляются автоматически после завершения работы и при следующем запуске, а также кнопкой «Очистить временные файлы» в настройках.

## 3. Реклама и рекламный SDK
Приложение использует Yandex Mobile Ads SDK (ООО «Яндекс»). Показываются баннер, полноэкранная реклама при каждом сжатии файлов и, по желанию пользователя, вознаграждаемая реклама (для отключения рекламы на время).

Для показа и учёта рекламы SDK может собирать и обрабатывать: рекламный идентификатор устройства (например, Google Advertising ID или аналог), IP-адрес, сведения об устройстве и системе (модель, версия Android, язык, размер экрана, тип сети, оператор), сведения о приложении, данные о показах, кликах и взаимодействии с рекламой, примерное местоположение по IP-адресу, а также диагностические данные (сбои и зависания). Разработчик не передаёт SDK ваши файлы, их имена или содержимое.

Обработка этих данных регулируется политикой конфиденциальности Яндекса: https://yandex.ru/legal/confidential/

Управлять персонализацией рекламы можно в настройках Android (на устройствах с сервисами Google — «Google → Реклама»: сброс или удаление рекламного идентификатора) либо в настройках устройства от производителя. Рекламу в приложении можно отключить на время, посмотрев несколько рекламных роликов (значок короны на главном экране).

## 4. Разрешения приложения
- INTERNET и ACCESS_NETWORK_STATE — только для загрузки и показа рекламы. Сжатие файлов работает без интернета.
- com.google.android.gms.permission.AD_ID — доступ к рекламному идентификатору для рекламного SDK.
- FOREGROUND_SERVICE, FOREGROUND_SERVICE_DATA_SYNC и POST_NOTIFICATIONS — чтобы сжатие не прерывалось при сворачивании приложения и показывало уведомление о ходе работы.

Приложение не запрашивает доступ ко всему хранилищу, контактам, геолокации, камере, микрофону и другим личным данным.
